# 特需領域核心素養結構化資料庫 (Special Education Core Competency JSON Database)

這是一個將台灣《十二年國民基本教育領域課程綱要特需領域發展手冊》中的內容，透過程式自動化解析後，建立的**結構化 JSON 資料庫**。

本資料庫旨在解決教師在撰寫特教/資優教案、個別輔導計畫 (IGP) 或觀課紀錄時，需要不斷手動翻閱 PDF 手冊與複製貼上的痛點。開發者或教師可直接讀取本 JSON 檔案，整合進自己的自動化腳本或系統中。

## 資料庫特色

1. **涵蓋全學段**：完整收錄國小 (E級)、國中 (J級)、高中 (U級) 三個教育階段的指標。
2. **涵蓋全領域**：包含「情意發展」、「創造力」、「領導才能」、「獨立研究」四大特需領域。
3. **巢狀精細分類**：跳脫過去單一指標的限制，資料庫嚴格區分出三大層級：
   - `核心素養` (Core Competencies)
   - `學習表現` (Learning Performances)
   - `學習內容` (Learning Contents)

## 資料結構說明

資料庫存放在 `output/` 目錄下，包含三個檔案：
- `special_ed_competencies_E.json` (國小階段)
- `special_ed_competencies_J.json` (國中階段)
- `special_ed_competencies_U.json` (高中階段)

**JSON 結構範例**：
```json
{
  "情意發展": {
    "核心素養": {
      "特情-J-A1": "具備對成功的合宜觀點，有效擬定自我精進計畫..."
    },
    "學習表現": {
      "特情1a-Ⅳ-1": "覺察並描述個人內在特質、能力與限制。"
    },
    "學習內容": {
      "特情A-Ⅳ-1": "自我概念與發展。"
    }
  },
  "創造力": {
    "...": "..."
  }
}
```

## 應用場景

- **教案自動生成**：讓 LLM (如 ChatGPT) 讀取此資料庫後，自動根據你的單元主題挑選適合的學習表現與學習內容。
- **IGP 自動填寫**：搭配 `python-docx` 等自動化腳本，將選定的核心素養自動寫入學生的個別輔導計畫表中。
- **數位觀課系統**：匯入資料庫作為前端選單，方便觀課教師快速點選對應指標。

## 開發歷史 (Changelog)

### [2026-08-02] 資料庫大升級與純淨化
- **學段擴充**：從原本僅有國中 (J級)，完整擴充補齊國小 (E級) 與高中 (U級) 資料庫。

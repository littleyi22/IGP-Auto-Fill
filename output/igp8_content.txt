| 學年/期  目標 | | 一、 文本深度解析與評鑑能力（分析與評鑑層次）  跨文類比較研究：精確解析童詩、近體詩、文言小品、小說等多元文本的修辭結構與美學風格，並能運用比較視角，分析不同時代背景下的文學核心價值。  思辨與詮釋能力：跳脫單一視角，運用邏輯分析文本的隱喻（如：「紙船」之於親情、「石虎」之於生態），並能針對文本中潛藏的人生課題與社會議題，進行多維度的辯證與評析。  二、 高階寫作與創作潛能（創造層次）  文本轉譯與創意表達：具備將抽象情感具象化、將複雜論點結構化的能力。能靈活運用排比、對比等修辭，產出具備深度觀點與個人風格的文學創作或數位敘事作品。  觀點建構與敘事整合：能從日常觀察中提煉議題，建立個人化的論述框架，並運用科技工具（如：NotebookLM、數位編輯平台）進行知識管理與創作發布，展現整合性思維。  三、 自主學習與後設認知（探究與自學層次）  問題導向探究（PBL）：針對生態保育、文化傳承等議題，能主動發現問題癥結，並結合科技應用，運用科學方法或跨學科知識進行探索，提出創新解決方案。  後設認知與合作機制：在合作學習中，能主動反思學習過程，評估不同策略的有效性，並展現領導力與協調能力，藉由溝通促進團隊知識共建。  四、 價值內化與人文關懷（情意層次）  多元文化與生命哲學：透過對文人人格（如：陶淵明）與社會價值（如：謝天、尼可拉斯效應）的探究，深刻體會多元文化的價值，建立「自我-社群-全球」的連結感。  社會責任與公民熱情：將語文能力轉化為參與公共事務的動力，運用所學關懷在地文化與全球永續議題，培養具備人文底蘊、社會實踐力的領袖型學習者。 | | | | | | | | | | | | | |
| 學習調整  (內容、歷程、環境、評量)  (可自行增減) | | **基礎檢測與動態加強：** 針對各課課內已經習得的語文知識進行形成性評量，精準檢測學生的學習狀況。針對同學該次評量不足的部分，及時予以動態輔導與個別化加強。   **自編教材之加深加廣：** 以課內知識點（如文體結構、格律美學、語文邏輯）為基礎，主要採用**資優資源班自編教材進行加深加廣教學**，其他教材為輔。引導數理與語文資優學生進行多元視角思考與深度文學探究。   **個別化策略與輔導建議：** 密切觀察學生的學習表現，依據學生的個別需要與興趣取向，適時提供高階閱讀與寫作策略，並給予具體的後設認知輔導建議。   **跨界校外資源之整合：** 適度引入校外資源（如規劃**校外參訪、大師專題講座、國際學伴交流**等），引導學生將文學脈絡與現實社會連結，增加其學習廣度與多元文化感受力。  • 空間彈性：專業抽離式學習空間 資源班學生（數理資優／語文資優生）於國文課時間抽離原班，移至專門之「語文資優教室」上課，以利實施具挑戰性的個別化與適性加深加廣課程。  • 模式彈性：實體與線上多元互動 依據不同單元的教學目標，靈活調整座位排列與學習型態。廣泛運用實體分組合作探究、小組討論，以及線上論壇交流（如 Padlet、數位共編平台）等多元學習方式，促進高層次同儕互動。  • 情境設計：潛能激發與包容環境 積極營造彼此傾聽、相互尊重不同觀點、樂於分享的班級氛圍；透過高階情境設計、大哉問探討與專題任務，提供高認知需求的心理安全環境，以激發學生展現卓越的資優潛能。  • 優勢能力引導之多元評量： 擺脫單一測驗框架，提供符合資優學生優勢能力的多元評量方式，評量項目包含：口語表達與論辯、蒐集資料與材料組織、主題寫作、小組報告、作業呈現、學習單、紙筆測驗、以及詩歌背誦。  • 學期成績計算比例：  • 段考成績占 40%：配合普通班段考（定期紙筆測驗分數），確保基礎學力的精熟度。  • 平時成績占 60%：由資優資源班教師依據加深加廣課程之歷程成果進行專業給分。  • 平時成績計算細則：  • 70% 作業及紙筆測驗：包含自編寫作講義、主題專題報告、高階提問學習單作業與單元形成性測驗。  • 30% 學習態度與口頭發表：包含課堂思辨與線上討論的參與度、同儕合作態度，以及口頭簡報、報告與評論發表時的邏輯展現。 | | | | | | | | | | | | | |

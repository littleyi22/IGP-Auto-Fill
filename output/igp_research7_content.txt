| 學年/期  目標 | | 一、 系統化思維與跨領域研究設計  整合型知識建構：培養學生跳脫學科疆界，運用研究方法（如：質性訪談、數據分析、田野調查）統整知識，並將其轉化為針對現實生活問題的分析框架，具備系統性思考能力。  二、 在地實踐與深層脈絡挖掘  田野探究與議題診斷：引導學生進入在地社區進行深度挖掘，從地理、歷史、社會經濟與文化符號等多重維度進行議題診斷，深化研究與地方脈絡（Context）的連結。  三、 觀點創新與地方認同建構  在地敘事與觀點論述：提升學生從「認識地方」轉化為「詮釋地方」的能力，鼓勵學生建立個人化的研究視角，產出具有原創性與批判性的地方研究作品，展現資優學生的思辨深度。  四、 學校與社區共融之影響力  創生型課程與社會實踐：連結學校本位課程與地方發展，透過議題發表、數位敘事傳播或行動方案設計，將學術研究產出轉化為具備文化保存、推廣意義的行動影響力，型塑獨特且具備在地影響力的知識臉譜。 | | | | | | | | | | | | | |
| 學習調整  (內容、歷程、環境、評量)  (可自行增減) | | 一、 教學策略與認知架構（Instructional Strategies）   1. 認知支持與鷹架建構：採用差異化教學，針對資優學生的認知特質，運用高階提問策略（如：蘇格拉底式提問）引導深度思考。適度運用多元感官與科技工具作為認知鷹架，並給予問題解決過程中的進階引導，而非僅是基礎提示。 2. 動態合作與知識共建：導入合作學習模式，建立異質或同質分組機制，創造高密度的人際互動與觀點碰撞，強調團隊協作中的批判思考與知識整合。   二、 學習環境與實地探究（Learning Environment & Fieldwork）   1. 高質感探究空間：固定於語資教室進行課程，並結合數位協作環境，營造以探究為導向（Inquiry-based）的專題研究室氛圍。 2. 深度田野調查（Fieldwork）：實地訪查不再侷限於觀察，要求學生設計研究工具（如：結構化訪談大綱、觀察量表），進入社區進行深度訪談與田野紀錄，並需產出具有學術或在地價值之調查報告。   三、 評量方式與多元產出（Alternative Assessment）   1. 歷程導向評量（Process-oriented）：大幅減少傳統紙筆測驗，改採「實作評量（Performance Assessment）」。針對操作課程、專題實作歷程建立客製化檢核表（Rubrics），將學生在研究、分析、溝通、解決問題等過程中的表現納入評分範疇。 2. 專題式產出（Project-based Product）：將單元學習單優化為「專題導向學習（PBL）模組」。學生需將研究成果轉化為具備公開發表價值的產出（如：數位簡報、策展提案、紀錄影片），並進行小組公開口頭發表與答辯，培養其領域知識的傳播能力。 | | | | | | | | | | | | | |

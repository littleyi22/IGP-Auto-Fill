# Auto Fill IGP (資優班個別輔導計畫自動填寫)

當使用者要求填寫空白的 IGP 文件（如 `116學年度IGP-九年級國文.docx`），並指定參考對應的課程總表時，請遵循以下步驟自動完成填寫。

## 1. 準備階段
- 確認使用者提供的空白 IGP 檔案路徑。
- 確認使用者提供的上、下學期課程計畫檔案路徑（如 `.doc` 或 `.docx`）。
- 確認特需領域核心素養的 JSON 檔案路徑（預設為工作區的 `output/special_ed_competencies_J.json`）。如果檔案不存在，請先協助抽取或向使用者確認。

## 2. 擷取課程計畫內容
- 讀取上、下學期的課程計畫。
- 若檔案為舊版 `.doc`，請撰寫 `win32com.client` Python 腳本轉譯為純文字；若為 `.docx`，則可使用 `markitdown` 模組或其他相應工具讀取。
- 提取出每一週的「起訖日期」、「單元名稱 / 教學重點 / 學習目標」。

## 3. 準備寫入資料
- **特需領域核心素養**：從 JSON 中挑選 10 項適合學生的素養（建議涵蓋情意發展、創造力、領導才能、獨立研究等），並格式化為帶有編號與說明的字串。
- **課程週次資料**：依據抽取的課程計畫，為每一週生成以下資訊：
  1. `起訖日期`：直接對應。
  2. `教學目標`：根據單元名稱與學習重點，濃縮成一段通順的教學目標。
  3. `教學方法`：填寫代碼組合（如 `a, c, f, g`）。代碼參考：a講述 b練習 c討論 d觀察 e實驗 f多媒體 g發表 h其他。
  4. `評量方式`：填寫代碼組合（如 `1, 3`）。代碼參考：1口頭發表 2書面報告 3作業單 4器材操作 5紙筆測驗 6其他。
  5. `評量紀錄/結果`：6個維度（主動學習, 認知能力, 作業表現, 表達能力, 同儕合作, 傾聽態度）的分數。請隨機分配：大多數5，少部分4，極少部分3。
  6. `評量日期`：通常為該週的最後一天。

## 4. 撰寫 Python 腳本更新 IGP
請使用 `python-docx` 撰寫腳本，直接修改 IGP 文件。
**IGP 文件的表格結構特徵**：
- 第一個表格 `doc.tables[0]` 包含了所有需要填寫的欄位。
- **特需領域核心素養**：位於 `table.rows[6].cells[2]`。
- **上學期週次（1-19週）**：位於 `table.rows[10]` 到 `table.rows[28]`。
- **下學期週次（1-19週）**：位於 `table.rows[30]` 到 `table.rows[48]`。

週次列的欄位對應（由於合併儲存格，請直接使用以下索引進行寫入）：
- `cells[1]`：教學目標
- `cells[4]`：起訖日期
- `cells[5]`：教學方法（代碼）
- `cells[6]`：評量方式（代碼）
- `cells[8]`：主動學習（分數）
- `cells[9]`：認知能力（分數）
- `cells[11]`：作業表現（分數）
- `cells[12]`：表達能力（分數）
- `cells[13]`：同儕合作（分數）
- `cells[14]`：傾聽態度（分數）
- `cells[15]`：評量日期

## 5. 儲存與版控
- 將填寫完成的檔案存為 `原檔名（已填寫）.docx`，放置於工作區的 `output/` 資料夾中。
- 檢查填寫結果是否有編碼或結構錯置問題。
- 使用 Git 進行 commit，訊息格式例如 `feat: 完成116學年度IGP表格填寫`。
